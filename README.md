# Solo Defending website

The public pages of Solo Defending, served by GitHub Pages at https://and-games-studio.github.io/solodefending/

- `index.html`: home page.
- `privacy/`: privacy policy (linked from the Play Store listing, AdMob's consent message and the game's Options).
- `terms/`: terms of service.
- `delete/`: how to delete the data the game keeps (the Play Console data safety form links it).

Plain HTML and CSS, no build step. The fonts are the game's, Alegreya SC and Alegreya Sans (SIL Open Font License 1.1, in `fonts/` with their licenses), served from here, so the site makes no requests to other servers.
